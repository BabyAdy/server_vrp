Vehicle images for the /v garage menu.

- One PNG per spawn model, named exactly after the model:  adder.png, sultanrs.png, ...
- Recommended size ~ 480x270 (16:9), transparent or dark background.
- _default.png  is the fallback shown when a model has no image.

Files are loaded through fxmanifest (html/img/*.png). Add _default.png before
going live so cards without an image still look right.
